# AIRA Project Roadmap

## Phase 0 — Setup

- Create monorepo and baseline project structure
- Initialize Git
- Add README and project docs
- Define board tasks and milestones

## Phase 1 — Product & UX

- Define borrower, lender, and admin journeys
- Prepare wireframes and user flow documents
- Finalize risk and fraud rules

## Phase 2 — Frontend MVP

- Borrower onboarding UI
- Lender dashboard UI
- Admin review panel
- Low-bandwidth responsive design

## Phase 3 — Backend API

- Authentication and role system
- Statement upload handling
- Consent management
- Trust score API

## Phase 4 — ML scoring

- Feature engineering from MFS statements
- Model training and evaluation
- SHAP explanations
- Lender-facing explanation layer

## Phase 5 — Blockchain

- Score hashing
- Ledger anchoring
- Verification endpoints
- Cross-lender portability

## Phase 6 — Launch prep

- Security review
- Deployment strategy
- Documentation and demo materials
- Presentation prep
