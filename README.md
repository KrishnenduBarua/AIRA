# AIRA

A webapp for the BCOLBD competition.

AIRA is an AI-powered alternative credit intelligence platform for financially active but credit-invisible individuals in Bangladesh.

## Monorepo structure

- `frontend/` — React app for borrower, lender, and admin experiences
- `backend/` — Express API layer and business logic
- `ml-model/` — ML scoring, explainability, and feature-engineering service
- `blockchain/` — blockchain anchoring and portability components
- `docs/` — product, architecture, and implementation documentation

## Getting started

1. Install frontend dependencies in `frontend/`
2. Install backend dependencies in `backend/`
3. Set up Python environment in `ml-model/`
4. Configure blockchain service in `blockchain/`
5. Review docs in `docs/`

## Phase roadmap

- Phase 0: setup and repo scaffolding
